Play together on LAN + Tailscale

  1. Host runs python app.py (binds 0.0.0.0:5000, debug off).
  2. Same Wi-Fi (LAN): join http://<host-lan-ip>:5000 (find via ipconfig / ifconfig). Allow Private firewall, block Public.
  3. Far away (Tailscale): install Tailscale on all devices, join same tailnet, then open http://<host-tailscale-ip>:5000 (or MagicDNS name). No port-forwarding.
  4. Start a game from the homepage — pick questions, difficulty, waiting time (10–300s). Everyone gets a banner + auto-open at live.
